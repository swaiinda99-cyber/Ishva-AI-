# Ishva AI - Multi-AI Coordination Protocol

This repository is actively co-developed by **Antigravity AI** and **Cursor AI**.

## Core Rules for Both AI Agents:
1. **Never Duplicate**: Always inspect existing files and directories before creating new ones.
2. **Check Before Working**: Read AI_TASK_BOARD.md and AI_COMMUNICATION.md before starting any task.
3. **Claim Your Task**: Before editing or creating files, register your task and touched files in AI_TASK_BOARD.md.
4. **Log Changes & Handoff**: After finishing or pausing a task, append an update in AI_COMMUNICATION.md.
5. **Respect File Locks**: Do not modify files marked as IN_PROGRESS by the other agent without prior coordination.
6. **Git Hygiene**: Always check for local or remote changes before committing (git pull --rebase). Prefix commits with your agent name (e.g., eat(antigravity): ... or eat(cursor): ...).
